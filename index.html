安装

三步放进你的直播间

不需要安装客户端，也不需要配置服务器。一个 Edge 扩展就够。以下以 Edge 为例；Chrome 的按钮名称见常见问题。

  1. 1

    解压压缩包

    在爱发电下载 zip，右键「全部解压缩」，得到 bilibili-live-assistant-v1.0.0 文件夹；打开后应能直接看到 manifest.json。放到固定位置，装好后不要移动或删除。

  2. 2

    加载扩展

    打开 edge://extensions/，点左下角「开发人员模式」；再点右上角「开发人员选项」里的「加载解压缩的扩展」，选择直接包含 manifest.json 的文件夹——不是 zip，也不是上一层。

  3. 3

    打开直播间

    刷新 B 站直播间；没看到图标就点右上角拼图固定。点图标打开弹窗，在「连接与房间」点「绑定当前」，确认「已连接 / 已认证」；需要时点「测试连拍」。

常见问题

买之前，你可能会问

支持哪些浏览器？

Edge 和 Chrome 内核的浏览器都可以，目前在 Edge 上测试得最多。Edge 在扩展页左下角打开「开发人员模式」，按钮叫「加载解压缩的扩展」；Chrome 在扩展页右上角打开「开发者模式」，按钮叫「加载已解压的扩展程序」。不需要上架应用商店。

我的电脑能用吗？

目前按 Windows 10/11 上的 Edge 和 Chrome 内核浏览器测试和交付，需要登录 B 站账号；手机和 macOS 没有测试，不建议购买。截图时还需要让直播间标签页保持前台。

付款后怎么收到下载链接？

付款后通过爱发电私信发送下载链接和安装说明，请留意站内信；收到后先解压压缩包，再按页面上的三步加载扩展。

安装时提示“清单文件缺失”或“无法加载扩展程序”？

说明文件夹层级选错了。回到解压后的目录，进入能直接看到 manifest.json 的那一层再选；不要选 zip、它的上一级，也不要选 manifest.json 文件本身。找不到开关时，开发人员模式在扩展页左下角，打开后「加载解压缩的扩展」在右上角「开发人员选项」里。装好后不要移动或删除这个文件夹，否则扩展会失效。

会不会触发风控或者封号？

不能保证。自动发弹幕、自动点赞都属于自动化操作，频率过高可能触发平台风控。扩展默认使用保守的发送间隔和每日上限，但仍需要你遵守 B 站的规则，风险由使用者自行承担。

为什么截图要求直播间保持前台？

浏览器只允许截取当前可见的标签页。截图时请让直播间标签页保持前台；礼物答谢、弹幕库和自动点赞不受这个限制。

会上传我的账号数据吗？

不会。扩展在本机运行，设置保存在浏览器存储里，截图保存在本机下载目录；不采集密码，也不会上传 cookie 或聊天记录。

怎么更新？

下载新版本压缩包，解压后覆盖原来的文件夹，再到扩展页点一次“重新加载”，刷新直播间即可。设置会保留，买断用户更新免费。

支持多直播间吗？

一次绑定一个直播间。留空房间号会跟随当前打开的直播间，但不建议同时开多个直播间同时运行截图。
